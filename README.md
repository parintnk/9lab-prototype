# 9lab-prototype

Review site for the 9Lab mobile store: customer journey, brief checklist, wireframe and clickable prototype, in English, ไทย, 繁體中文 and 简体中文.

```bash
npm install
npm run build:html   # wireframe + prototype in 4 languages
npm run dev          # http://localhost:3000
npm run build        # static site in out/
```

Project notes, decisions and how to edit translations: [NOTES.md](NOTES.md)
